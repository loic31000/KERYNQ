# Code de conduite

KERYNQ est actuellement développé dans un dépôt privé. Les règles suivantes s'appliquent aux personnes autorisées à collaborer et à la communauté future.

## Comportement attendu

- Échanger avec respect, notamment lors des désaccords techniques.
- Argumenter avec des faits, des tests et des exemples reproductibles.
- Respecter la vie privée, les droits d'auteur et le travail d'autrui.
- Accueillir les contributions des personnes de tous niveaux d'expérience.
- Accepter les retours constructifs, sans attaque personnelle.

## Comportements interdits

- Harcèlement, intimidation, menaces ou divulgation d'informations privées.
- Messages discriminatoires ou attaques ciblées.
- Spam, usurpation d'identité, promotion non sollicitée.
- Divulgation publique de vulnérabilités non corrigées ou de données personnelles.

## Modération et contact

Le propriétaire du dépôt décide des actions nécessaires : avertissement, retrait de contenu ou limitation d'accès. Pour un problème de comportement, demander un échange privé au propriétaire via son profil GitHub ; ne pas publier de détails personnels dans une issue. Les signalements de sécurité suivent [SECURITY.md](SECURITY.md).
