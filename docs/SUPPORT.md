# Assistance et questions fréquentes

KERYNQ est en **prépublication privée**. Aucun support commercial ou délai de réponse garanti.

## Questions fréquentes

- **Est-ce un moteur autonome ?** Non. KERYNQ prépare des requêtes, qui s'ouvrent dans le moteur sélectionné.
- **L'IA répond-elle dans KERYNQ ?** Non. La consigne est générée localement, à copier, puis l'assistant choisi s'ouvre dans un autre onglet.
- **Faut-il une clé API ou un abonnement ?** Non pour utiliser KERYNQ. Les sites tiers peuvent appliquer leurs propres règles.
- **Mes favoris sont-ils synchronisés ?** Non, stockage local au navigateur uniquement. Export/import manuel disponible.
- **Pourquoi certains filtres ne marchent pas sur le Web ?** Les moteurs n'acceptent pas tous les mêmes opérateurs. Certains critères n'ont de sens que dans une consigne IA.
- **Puis-je utiliser KERYNQ sans Internet ?** Préparer des requêtes, oui, si le fichier est disponible localement ; lancer une recherche externe, non.

## Demandes

Lorsque le dépôt sera ouvert, utilisez les modèles d'issue **Bug** ou **Amélioration**. Pour les vulnérabilités, lisez impérativement [SECURITY.md](SECURITY.md), ne créez pas d'issue publique détaillée.
