**Aucune licence de logiciel libre / open source n'a été accordée pour KERYNQ à ce jour.** Le dépôt est actuellement privé. Toute permission de reproduire, modifier, redistribuer ou incorporer le code doit être obtenue directement auprès du titulaire des droits, sous réserve des exceptions légales applicables.

Ce fichier sert à rendre explicite le statut **actuel**, pas à prétendre qu'il existe déjà une licence MIT, Apache-2.0 ou GPL. Une licence définitive sera ajoutée **sur instruction explicite du propriétaire**, avant publication open source.

Options à étudier :

- **MIT** : permissive, courte ; facilite la réutilisation avec attribution.
- **Apache-2.0** : permissive, avec des dispositions explicites sur les brevets.
- **GPL-3.0** : copyleft pour les redistributions de versions modifiées.

Avant tout choix : inventorier les dépendances, polices, icônes et visuels (notamment l'illustration du globe) afin de s'assurer que leurs conditions de redistribution sont compatibles.
